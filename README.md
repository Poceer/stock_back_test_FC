# 股票对比回测 (Stock Backtest FC)

一个轻量的**多股票收益率对比回测**工具。输入若干股票代码，一键生成各周期收益率明细 + Z-score 综合得分排名图表。

🌐 **在线访问**：<https://poceer.github.io/stock_back_test_FC/>

---

## 功能简介

- **多股票横向对比**：一次最多输入十几只股票，自动拉取历史日线数据
- **多周期收益率明细**：统计 5 / 15 / 30 / 60 / 90 / 180 日的涨跌幅
- **Z-score 综合评分**：对每个周期做横截面标准化，等权累加得到每只股票的综合得分
- **可视化排名**：上下双图展示
  - 上图：各周期收益率明细（按涨幅逆序）
  - 下图：Z-score 加权总分排名（横向条形图）
- **快捷板块**：内置 SOC、锂矿、网络安全、算力 等板块一键填充

---

## 使用方法

1. 打开 <https://poceer.github.io/stock_back_test_FC/>
2. 点击顶部的**快捷板块**按钮快速填充，或手动在输入框中输入股票代码（英文逗号分隔）
3. 点击 **开始分析**
4. 等待约 10~30 秒，页面会显示回测图表

### 输入格式示例

```
603893,301536,688099
```

> 也支持带前缀的代码（如 `sh600519`、`sz000001`），后端会自动解析。

## 评分逻辑

1. 对每只股票，计算它在各周期（5/15/30/60/90/180 日）的涨跌幅
2. 对**每个周期**，在所有股票之间做横截面标准化：
   ```
   z = (该股票涨幅 - 同期均值) / 同期标准差
   ```
3. 每只股票把各周期的 Z-score **等权累加**，再除以有效周期数，得到最终得分
4. 按得分从高到低排名

> 得分越高，代表该股票在多个周期上的相对表现越强。
